# セキュリティエンジニア基礎チャレンジ

全80問の問題バンクから毎回20問を組み合わせる、4択の学習用知識テストです。自己申告によるセキュリティ自己チェックとは別の機能です。

## 範囲と合否

| 分野 | 主な内容 | バンク | 毎回の出題 |
| --- | --- | --- | --- |
| ネットワークの基礎 | アドレス・経路、DNS、TCP/UDP、TLS、境界制御、分離 | 20問 | 5問 |
| Webとアクセス制御 | HTTP、認証・認可、セッション、権限と信頼の境界 | 20問 | 5問 |
| 安全なWeb開発 | インジェクション、ブラウザの保護、入力・ファイル・秘密情報、依存先 | 20問 | 5問 |
| 運用と復旧 | 更新、記録、バックアップ・復旧、インシデント対応 | 20問 | 5問 |

1問5点、100点満点です。全20問の有効な回答が揃ってから採点し、90点以上を「合格」、90点未満を「不合格」と表示します。
18問正解は90点で合格、17問正解は85点で不合格です。未回答や存在しない選択肢を正解に数えたり、得点の分母から除いたりしません。

合格ラインは利用者の依頼に基づく本アプリの学習用ルールです。公的試験、資格認定、実技評価、公式なセキュリティ適合判定ではありません。
ネットワークからWeb開発までの入口として基本の考え方を確認するもので、必要なすべての実務能力を網羅した試験ではありません。

## 操作と復習

各分野から5問ずつ、計20問を抽選します。未出題を優先するため、履歴が空の状態から最初の4回は80問を重複なく一巡します。
一巡後も、直近2回の抽選済み20問ずつを除いた候補からランダムに組み合わせます。同じ4組を繰り返すだけにはしません。
問題と選択肢の順序も開始時・再挑戦時に並べ替えます。位置やA/B/C/Dではなく、問題IDと選択肢IDで採点します。
途中で終了した挑戦も、開始時に抽選した20問を履歴に含めます。新しい問題が追加された場合は、その未出題問題を優先します。
将来カスタマイズして候補が不足した場合は、必要な数だけ古い履歴から再出題し、各分野5問を確保します。
回答を選ぶと約0.3秒後に自動で次へ進みます。「前の問題」で回答を修正できます。
結果に、合否、得点、正解数、分野別の成績、全問の正誤・選択・正解・解説・出典を表示します。誤答優先または分野別に復習できます。
連打と遅延処理の競合を防ぎ、退出前には回答と結果を消去する確認を表示します。

## 根拠とデータ

`data/challenge.json` の各問題に、公開一次資料のタイトル、出版社、HTTPSリンク、参照箇所を持たせています。
IETF/RFC Editor、NIST、OWASP、MDN Web Docs、CIS、Microsoft Learn等を参考に、問題・選択肢・解説を独自に記述しています。
問題文は各組織の公式試験問題の転載ではありません。リンク先資料や商標の権利は各権利者に属します。

`js/challenge-engine.js` がバンク検証・分野別抽選・履歴正規化・並べ替え・採点・分野別集計、`js/challenge.js` が画面と操作・履歴の保存を担当します。
`tests/challenge.test.cjs` で80問の構成、未出題優先、直近2回の重複回避、履歴復元・不正値・小規模バンク、90点の境界、未回答、回答修正、並べ替え後の採点と原稿保持を検証します。

回答と結果はブラウザのメモリーだけで保持し、外部へ送信せず、自動保存もしません。タブを閉じたり再読み込みすると消去されます。
再読み込み後も重複を避けるため、出題済みの公開問題IDだけをlocalStorageの `security-challenge-question-history-v1` に保存します。
保存形式は `{version:1, ids:[...]}`、IDは古い順・重複なし・現行バンクの問題数以内（現在80）です。回答・得点・正誤・個人情報は含みません。
開始画面の「出題履歴をリセット」で消去できます。保存できないブラウザでは、同じページを開いている間だけメモリーの履歴で動作します。
同じオリジン・ブラウザの利用者で履歴を共有し、端末間同期はありません。複数タブで同時に開始した場合は重複することがあります。
JavaScriptと問題の正解は公開ソースに含まれるため、不正防止が必要な資格試験の運用には使用しません。
